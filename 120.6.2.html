3 分鐘速覽

Filter、dashboard、subscription

  1. 分享要權限Share dashboards and filters 全域權限；可分享給 user、group、project（role）、組織、public。
  2. 看到的結果因人而異被分享的人只看得到自己有權限的 issue。
  3. SubscriptionFilter → Subscribe：寄給自己或 group；排程 daily、days per week、days per month、advanced（cron）；可選沒結果也寄。
  4. 訂閱給 group要 Manage group filter subscriptions；每位成員依自己的權限收到結果。
  5. currentUser() 在訂閱依每位收件人分別計算：每個人收到「自己的」清單。
  6. Default dashboardJira admin 設定；每個人預設看到它，可以自己另建。
分享

Filter 與 dashboard 的分享

  1. 存 filterSearch → Save filter → 名稱。
  2. 分享Filter details → Edit permissions：Viewers（user、group、project／role、organization、public）與 Editors。
  3. DashboardDashboards → Create dashboard → 分享給誰 → 加 gadget（多數 gadget 使用 saved filter）。
  4. 公開風險分享給 public 會讓匿名使用者看到；admin 可在設定中防止或移除 public access。
考題長相

「Dashboard 分享給整個 Sales group，有人看到的 gadget 是空的」→ 他對 filter 中的 project 沒有 Browse 權限（或 filter 沒分享給他）。

本段必考
  • 分享 filter 不等於給權限。
