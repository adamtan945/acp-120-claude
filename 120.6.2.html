Filter、dashboard、subscription

  1. 分享要權限Share dashboards and filters 全域權限；可分享給 user、group、project（role）、組織、public。
  2. 看到的結果因人而異被分享的人只看得到自己有權限的 issue。
  3. SubscriptionFilter → Subscribe：寄給自己或 group；排程 daily、days per week、days per month、advanced（cron）；可選沒結果也寄。
  4. 訂閱給 group要 Manage group filter subscriptions，且只能選自己是成員的 group；每位成員依自己的權限收到結果；信中只列前 200 筆。
  5. currentUser() 在訂閱依每位收件人分別計算：每個人收到「自己的」清單。
  6. Default dashboardJira admin 設定；每個人預設看到它，可以自己另建。

分享

Filter 與 dashboard 的分享

  1. 存 filterSearch → Save filter → 名稱。
  2. 分享Filter details → Edit permissions：Viewers（user、group、project／role、organization、public）與 Editors。
  3. DashboardDashboards → Create dashboard → 分享給誰 → 加 gadget（多數 gadget 使用 saved filter）。
  4. 公開風險分享給 public 會讓匿名使用者看到；admin 可在設定中防止或移除 public access。

Dashboard 與 gadget

Dashboard 長什麼樣、gadget 怎麼挑

  • 任何 Jira 使用者都能建立自己的 dashboard；Rename or share 設定 Viewers 與 Editors（分享要有 Share dashboards and filters 全域權限）。
  • Gadget 用的 filter 要分享給觀看者，觀看者也要對結果有 Browse 權限，否則看到空白或沒有結果。
  • Dashboard 移到 trash 後只有 Jira admin 能還原，60 天後永久刪除。
  • 每個 gadget 的長相與用途：報表與 gadget 圖鑑。下面是最常考的四個。

Filter Results

清單資料：saved filter

把 filter 的結果列成清單，可自選欄位與筆數。

考點　內容由 filter 決定；filter 要分享給觀看者，觀看者也要有 Browse 權限才看得到結果。
資料來源（1）有疑慮時點開看官方原文
  • Filter Results GadgetDisplays the results when you filter work items.

Pie Chart

分佈資料：filter 或 space

依一個欄位（statistic type）畫佔比圓餅。

考點　一次只能一個欄位，算張數。
資料來源（1）有疑慮時點開看官方原文
  • Pie Chart GadgetDisplays work items from a space or work item filter, grouped by a statistic type, in pie-chart format.

動手做

實作 Lab：一個 filter，Leo 和你收到不同的訂閱信

約 30 分鐘你（Jira admin，有 Share dashboards and filters 與 Manage group filter subscriptions）

第一次做 Lab？先看 Lab 環境準備：用測試站台、準備測試帳號。畫面名稱可能隨 Atlassian 更新而不同，以下以現行畫面為準。

目標：建一個用 currentUser() 的 filter，分享給 team-leads、做成 dashboard、訂閱給 group，看每個人看到的結果都不一樣。

這個 Lab 對應的考點

分享 filter 不等於給權限：被分享的人只看到自己有權限的 issue；訂閱給 group 要 Manage group filter subscriptions、只能選自己所在的 group，currentUser() 依每位收件人計算；信中只列前 200 筆。

準備

  • 把你自己加進 team-leads（只能分享、訂閱給自己所在的 group）。
  • WEB 有 2 張指派給你、2 張指派給 Leo 的未解決 issue（120.6.1 的準備）。

步驟

  1. 你應該看到：Filter 名稱出現在頁面上方，旁邊有 Details。
  2. 你應該看到：Viewers 列出 team-leads。分享只決定誰看得到這個 filter；對方仍只看得到自己有 Browse 權限的 work item。
  3. 你應該看到：Leo 看得到這個 filter，結果是指派給 Leo 的 2 張，不是你的。
  4. 你應該看到：找不到：沒有分享給 Kim 所在的任何 group 或 role。
  5. 你應該看到：你和 Leo 看同一個 dashboard，gadget 列出的是各自的 issue。
  6. 你應該看到：訂閱建立成功。Recipients 能選 group，是因為你有 Manage group filter subscriptions，而且你在 team-leads 裡。
  7. 你應該看到：兩封信內容不同：你的列出你的 2 張、Leo 的列出 Leo 的 2 張。結果依每位收件人的權限與 currentUser() 計算。

試試看：改一個設定，觀察差異

T1把 Leo 從 WEB 的 Developers 暫時移除（沒有 Browse），用 Leo 重新整理 Lab WEB dashboard。看結果
Gadget 變空：filter 還是分享給 Leo，但他看不到 WEB 的 issue。分享 filter 不等於給權限。做完把 Leo 加回。
T2在 ⚙ Settings›System›Global permissions 把 Share dashboards and filters 從一般使用者的 group 移除。用 Leo 存一個自己的 filter，打開 Details。看結果
Leo 找不到分享設定（或無法新增 viewer）。做完把權限加回原本的 group。
T3編輯訂閱：把 JQL 改成一定沒結果（例如加上 AND labels = nothing），不勾 Email this filter even if there are no issues found，等下一次寄送時間。看結果
沒有人收到信：沒有結果預設不寄。勾選後才會寄空結果的信。
心像錨點：閉上眼睛想一次這個畫面

同一個時間點，兩個信箱各收到一封 Lab My WEB work：你的信列你的 issue，Leo 的信列 Leo 的 issue。分享看權限、訂閱看個人。

收尾

  • 刪除訂閱、Lab WEB dashboard 與 Lab My WEB work filter。
  • 把你自己移出 team-leads；確認 Share dashboards and filters 與 Leo 的 Developers role 都已恢復。
