3 分鐘速覽

Mail handler：email 變成 issue 或留言

  1. 設定位置Settings → System → Mail → Incoming Mail：先有 mail server（Google、Microsoft 用 OAuth；或 POP／IMAP），再加 mail handler。
  2. Handler 類型Create or comment（主旨有 issue key 就留言，沒有就建 issue）、只建 issue、只留言（全文、去除引用、marker 之前）。
  3. Default reporter寄件人不是 Jira 使用者時用這個帳號當 reporter（要有 Create Issues）；原寄件人寫在 description 末尾。
  4. CC assignee指派給第一個 CC 的使用者；沒有就看 To、再看 BCC；都沒有就不由 handler 指派。
  5. 其他選項Project、issue type、strip quotes、catch email address、bulk（ignore／forward／delete／accept）、forward email、CC watchers。
  6. 限制超過 7 天的信不處理；SPF 驗證失敗會被拒。
Handler

類型與選項

Handler做什麼
Create a new issue or add a comment to an existing issue主旨有 issue key → 留言；沒有 → 在預設 project 建 issue
Create a new issue from each email message每封都建新 issue
Add a comment with the entire email body整封內容當留言（主旨要有 key）
Add a comment from the non quoted email body去掉以 > 或 | 開頭的引用行
Add a comment before a specified marker or separator用 split regex 切掉回覆、轉寄的部分
選項說明
Project／Issue type新 issue 的預設 project 與類型
Default reporter寄件人不是使用者時的 reporter（需 Create Issues 與 Add Comments）
CC assignee第一個 CC → To → BCC 中有效的使用者
CC watchers把 CC 的使用者加為 watcher
Catch email address只處理寄給特定別名的信（一個 handler 一個）
Strip quotes移除引用的舊回覆
Bulk自動寄出的信：ignore、forward、delete、accept
Forward email處理失敗時通知的信箱
本段必考
  • 主旨有 key → 留言。
  • Default reporter 讓非使用者也能建單。
