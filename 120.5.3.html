個人通知設定

考你使用者能在個人設定調整哪些通知，以及它和 admin 設定的關係。

3 分鐘速覽

個人設定是濾網，不是加碼

  1. 位置右上 Settings → Personal Jira settings → Notification settings（與 General settings）。
  2. 濾網個人設定疊在 admin 設定之上：可以少收，不能多收 admin 沒設定的通知。
  3. 可選Watching、reporter、assignee、被 mention、自己做的變更；也可全關 email。
  4. Watch your work items開啟後，自己建立或留言的 issue 會自動 watch。
  5. 摘要信零碎更新最多延遲 10 分鐘合併成一封；mention、指派、SLA 等重要通知立即寄。
  6. 每個 project 可客製最多 50 個 space 各自設定。
資料來源（5）有疑慮時點開看官方原文

  • Manage your Jira personal settingsWith this enabled, you become a watcher of any work item that you create or comment on.
  • Manage your Jira personal settingsTo make sure relevant updates are batched together, notifications could be delayed by up to 10 minutes.
  • Manage your Jira personal settingsImportant notifications will come through immediately, like mentions, alerts, SLA notifications, and newly assigned work items.
  • Manage your Jira personal settingsUse the Customize space notifications section to set specific notifications for different spaces.

動手做

實作 Lab：Leo 的個人通知設定：只能少收

約 20 分鐘任何使用者（admin 端的對照要 Jira admin）

第一次做 Lab？先看 Lab 環境準備：用測試站台、準備測試帳號。畫面名稱可能隨 Atlassian 更新而不同，以下以現行畫面為準。

目標：用 Leo 的個人 Notification settings 關掉一類通知、保留 mention，再從 admin 端拿掉收件人，證明個人設定是濾網、不能多收。

這個 Lab 對應的考點

個人設定疊在 admin 設定上，只能少收；零碎更新最多延遲 10 分鐘合併成摘要，mention、指派等重要通知立即寄；Watch your work items 讓自己建立或留言的 issue 自動 watch。

準備

  • WEB 使用 WEB Notification Scheme（120.5.1 的準備），Issue commented 有 All watchers。
  • 挑兩張 WEB 的 issue：A（Leo 不是 assignee、reporter）、B（Leo 沒碰過）。

步驟

  1. 你應該看到：看到總開關 Send me emails for work item activity，以及 watching、reporter、assignee、mentions、自己的變更等勾選框，email 與 in-app 分開勾。
  2. 你應該看到：最多 10 分鐘內，Leo 別名的信箱收到 A 的留言通知（Leo 是 watcher）。
  3. 你應該看到：Leo 這次沒收到信，雖然他仍是 watcher、scheme 也沒改。
  4. 你應該看到：Leo 很快收到 mention 的信：mention 那一項還勾著，而且 mention 屬於立即寄的重要通知。
  5. 你應該看到：Leo 自動成為 B 的 watcher（B 的 watcher 數加 1）。
  6. 你應該看到：Leo 通常只收到一封合併的摘要信（最多延遲 10 分鐘），不是三封。

試試看：改一個設定，觀察差異

T1把 Leo 的 You're watching 勾回來。用你到 ⚙ Settings›Work items›Notification schemes → WEB Notification Scheme，把 Issue commented 的 All watchers 拿掉，再在 A 留言。看結果
Leo 收不到：admin 沒設定的通知，個人怎麼勾都收不到。個人設定只能少、不能多。做完把 All watchers 加回。
T2用 Leo 把總開關 Send me emails for work item activity 關掉，再在 A 留言。看結果
Leo 收不到 issue 活動信；但 filter subscription、站台公告等其他信仍會寄（120.6.2 的訂閱信不受這個開關影響）。做完打開。
T3（想像，不實際做）Mia 是 watcher、scheme 也有 All watchers，她卻收不到。看結果
先查她的個人 Notification settings（You're watching 是否關掉），再查她對該 issue 有沒有 Browse（含 issue security）。
心像錨點：閉上眼睛想一次這個畫面

Leo 的 Notification settings 頁：最上面一個總開關，下面一排勾選框。Admin 開水龍頭，個人只能裝濾網。

收尾

  • Leo 的 Notification settings 恢復全部勾選、總開關打開。
  • WEB Notification Scheme 的 Issue commented 確認有 All watchers。
  • Leo 可以取消 A、B 的 watch。
