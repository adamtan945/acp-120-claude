3 分鐘速覽

Project details：誰能改、改了會怎樣

  1. Project admin 能改Name、URL、Avatar、Description、Project lead、Default assignee。
  2. Project admin 不能改Key 與 Category（Jira admin；key 也可由 org、site admin 改）。
  3. 改名自動更新所有 filter 中的名稱。
  4. 改 key舊 key 存成 previous key，舊連結、filter、JQL 繼續有效；舊 key 不能被新 project 使用；description 裡的文字別名不會被改。
  5. Default assignee只有 Unassigned 或 Project lead。
  6. 側欄（sidebar）Project admin 可調整導覽：隱藏或顯示功能、加 shortcuts。

動手做

實作 Lab：改 WEB 的名稱與 key，看舊連結還能不能用

約 20 分鐘Jira admin（只有 org、site、Jira admin 能改 key）

第一次做 Lab？先看 Lab 環境準備：用測試站台、準備測試帳號。畫面名稱可能隨 Atlassian 更新而不同，以下以現行畫面為準。

目標：分別用 project admin 與 Jira admin 打開 Details，改名、改 key，再驗證 filter、舊網址、JQL 與 description 裡的舊 key。

這個 Lab 對應的考點

Project admin 能改 name、URL、avatar、description、project lead、default assignee；key 與 category 要 Jira admin。改名會自動更新 filter；改 key 後舊 key 成為 previous key，舊連結、filter、JQL 繼續有效，description 裡的文字不會被改寫，舊 key 也不能給新 project 用。

準備

  • 暫時把 Leo 加進 WEB 的 Administrators role（讓 Leo 是 project admin）。
  • 在 WEB 的第二張 issue 的 description 打一段文字 WEB-1。
  • 搜尋 project = "Web App"（用名稱，不用 key），Save as filter，命名 LAB WEB filter。

步驟

  1. 你應該看到：Leo 改得到 Name、URL、Description、avatar、Space owner、Default assignee；Key 欄位通常是灰色或存不了（要 Jira admin）。
  2. 你應該看到：Filter 的查詢自動變成新名稱，結果不變，不用手動改。
  3. 你應該看到：只有 Unassigned 與 Space owner（project lead）。想預設指派給某人，要先把他設成 Space owner。
  4. 你應該看到：Key 改好；之後新 issue 是 WAPP-n。Board 上的 key 可能要等一下才更新。
  5. 你應該看到：舊網址導向 WAPP-1；JQL 用舊 key 也查得到。
  6. 你應該看到：文字仍是 WEB-1，沒有被改寫成 WAPP-1；點它仍導到 WAPP-1。
  7. 你應該看到：列出 WEB：舊 key 被保留下來當 alias。
  8. 你應該看到：Key 回到 WEB，舊連結照常可用；WAPP 通常會留在 Previous space keys。後面的 Lab 都用 WEB，這步一定要做。

試試看：改一個設定，觀察差異

T1Create space → 選 Team-managed → 名稱隨便填，Key 填 WAPP（看完取消）。看結果
通常會提示 key 不能用：previous key 不能給新 space 用，除非原本的 space 被刪除或刪掉這個 previous key。
T2用 Leo（project admin）在 Details 改 Category。看結果
改不了：改 CMP 的 category 要 Administer Jira。Project admin 管外觀與人，不管 key 與 category。
T3用 Leo 在 WEB 的側欄找調整導覽的選項，加一個 shortcut（例如 Confluence 的網址）或隱藏一個用不到的功能。看結果
Project admin 就能調整 space 的側欄，不用 Jira admin。選單位置常改，找不到就略過這題。
心像錨點：閉上眼睛想一次這個畫面

Details 頁：Space key 欄位下面多了一行 Previous space keys：WEB。舊 key 不會消失，只是退到後面當 alias。口訣：名、網、圖、述、主、派。

收尾

  • Name 改回 Web App；確認 Space key 是 WEB。
  • （選做）在 Previous space keys 刪掉 WAPP：只有 org、site、Jira admin 能刪；刪了之後用 WAPP 的連結會失效，這裡沒人用，所以無妨。
  • Leo 移出 WEB 的 Administrators role；刪除 LAB WEB filter；description 裡的 WEB-1 可留著。
