3 分鐘速覽

三種 admin：org admin、Jira admin、project admin

  1. Org admin最高：管使用者、group、app 存取、安全政策；唯一能指派其他 org admin、site admin、Jira 的 app admin。
  2. Site admin管理 site 上的 app 與 Marketplace app；要有 Jira 授權才能用 Jira 功能。
  3. Jira admin（app admin）Administer Jira 全域權限；建 project、改 scheme、workflow、欄位。不能管使用者、不能匯入匯出、不能改系統 email。
  4. Project adminAdminister Projects 權限（CMP）或 Administrator role（TMP）；只管自己的 project。
  5. Org／site admin 也要把自己加進 jira-administrators才有 Administer Jira。
  6. 用 group 授權 admin把人加進 admin 的 default group，例如 jira-admins-xxx、org-admins。

  • Jira admin 不能管使用者、不能 backup／import。
  • Project admin 管 role 成員、不管 scheme。
授權方式

怎麼把人變成 admin

  1. Org adminAtlassian Administration → Directory → Users → 選人 → ••• → Assign organization admin role（只有 org admin 能做）。
  2. Site admin選人 → ••• → Assign site admin role（只有 org admin）。
  3. Jira admin（app admin）選人 → Grant access → Jira Administration 選 App admin（只有 org admin 能指派 Jira 的 app admin）。或加進 jira-admins-xxx group。
  4. Project adminJira admin 在 permission scheme 把 Administer Projects 給 Administrators role；project admin 再把人加進該 role。TMP 則直接給 Administrator role。
admin 不等於有授權

官方：admin 角色不一定自動給 app 存取；site admin 若要用 Jira 功能，仍需要 Jira 授權。

本段必考
  • Org admin 是唯一能指派 org、site、Jira app admin 的人。
易錯觀念

考題愛用的錯誤說法

Jira admin 可以邀請新使用者。
Administer Jira 不能管理使用者；那是 org admin（或 user access admin）的工作。
官方來源
Site admin 自動擁有 Administer Jira。
要加入 jira-administrators group（並有 Jira 授權）。
官方來源
Project admin 能改 permission scheme。
Project admin 只管 role 成員；scheme 要 Jira admin。
官方來源
Site admin 可以指派另一個人為 site admin（集中式介面）。
只有 org admin 能指派 site admin。
