Backup、restore 與匯入

  1. Backup managerSettings → System → Backup manager → Create backup for cloud；可勾附件、avatar、logo。
  2. 頻率含附件時兩次 backup 至少間隔 48 小時。
  3. 包含Issue 與欄位、board／sprint、使用者與 group、留言、設定（workflow、scheme、screen…）、archived projects。
  4. 不包含Automation rules（要另外匯出）、第三方 app 資料、Opsgenie 功能、Assets、app access 設定。
  5. Restore（匯入 backup）會覆蓋站上所有資料；Atlassian Backup & Restore 只能還原到沒有資料的 app、30 天內的 backup。
  6. 其他匯入CSV、JSON、Trello 等 importer 把資料加進現有 project，不覆蓋。

Restore 與匯入

覆蓋 vs 新增

方式效果適合
匯入 Jira Cloud backup（site import）覆蓋站上所有資料與設定；archived projects 也一起回來整站還原、搬站
Atlassian Backup & Restore（org admin）還原 30 天內的 backup 到沒有資料的 app；app access 要另外核准災難復原
CSV／JSON importer新增 issue 到指定 project；可對應欄位、建立使用者從其他工具搬資料
Trello importer把 board 匯入成 Jira project從 Trello 轉換
Jira Cloud Migration Assistant加入資料、不覆蓋；有些東西不搬（dashboards、filter subscriptions、webhooks、跨 project board）Server／DC 到 Cloud
還原前

匯入完整 backup 會覆蓋所有現有資料。先做目前站台的 backup；只想加入部分 project，用 CSV／JSON 或調整 backup 檔（官方 KB：partial import）。

本段必考
  • Site import＝覆蓋；CSV／JSON＝新增。
