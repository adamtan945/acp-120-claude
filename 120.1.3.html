Global permissions

Global permission 是全站能力。考你每個權限做什麼、為什麼只能給 group，以及和 project 權限的關係。

3 分鐘速覽

Global permissions：全站能力，只能給 group

  1. Administer JiraJira admin：建 project、改 issue type、欄位、workflow、scheme；不能管使用者、匯入匯出、系統 email。
  2. Browse users and groupsUser picker 與 @mention 看得到全站使用者；沒有的人只看得到在該 project 有 Browse 的人。
  3. Share dashboards and filters能把 filter、dashboard 分享給其他人。
  4. Manage group filter subscriptions能建立、刪除給 group 的 filter subscription。
  5. Make bulk changesBulk 編輯、移動、刪除、轉換（還要 project 權限）。
  6. Create team-managed projects只能建 TMP；建 CMP 要 Administer Jira。
權限清單

每個 global permission 的用途

Global permission能做什麼沒有時
Administer Jira建 CMP 與 TMP、改 issue type、欄位、workflow、各種 scheme；不受存取限制可登入不能改全站設定
Browse users and groups看到全站使用者（user picker、@mention）只看得到在該 project 有 Browse 權限的人
Share dashboards and filters分享 filter、dashboard 給 group、project、role、public只能私用
Manage group filter subscriptions建立、刪除給 group 的訂閱只能訂閱給自己
Make bulk changesBulk edit／move／delete／transition（仍需 project 權限）看不到 bulk change 選項
Create team-managed projects建立 TMP不能建 TMP（預設是所有 Jira 使用者都有）
Manage custom onboarding建立與編輯自訂 onboarding 內容—
本段必考
  • Bulk change 要 global＋project 兩層。
  • Browse users and groups 影響 @mention 範圍。
授予

Global permissions 只能給 group

  1. 位置⚙ Settings → System → Security → Global permissions。
  2. 授予選 permission → 選 group → Add。只能選 group（不能選單一使用者或 project role）。
  3. 收回在列表中 Remove。
  4. 要給一個人先由 org admin 把他放進某個 group，再把權限給那個 group。
考題長相

「只想讓 Mia 能分享 dashboard」→ 建立（或使用）一個包含 Mia 的 group，再把 Share dashboards and filters 給這個 group。Global permission 不能直接給個人。
