Global permissions

Global permission 是全站能力。考你每個權限做什麼、為什麼只能給 group，以及和 project 權限的關係。

3 分鐘速覽

Global permissions：全站能力，只能給 group

  1. Administer JiraJira admin：建 project、改 issue type、欄位、workflow、scheme；不能管使用者、匯入匯出、系統 email。
  2. Browse users and groupsUser picker 與 @mention 看得到全站使用者；沒有的人只看得到在該 project 有 Browse 的人。
  3. Share dashboards and filters能把 filter、dashboard 分享給其他人。
  4. Manage group filter subscriptions能建立、刪除給 group 的 filter subscription。
  5. Make bulk changesBulk 編輯、移動、刪除、轉換（還要 project 權限）。
  6. Create team-managed projects只能建 TMP；建 CMP 要 Administer Jira。

權限清單

每個 global permission 的用途

Global permission能做什麼沒有時
Administer Jira建 CMP 與 TMP、改 issue type、欄位、workflow、各種 scheme；不受存取限制可登入不能改全站設定
Browse users and groups看到全站使用者（user picker、@mention）只看得到在該 project 有 Browse 權限的人
Share dashboards and filters分享 filter、dashboard 給 group、project、role、public—

授予

Global permissions 只能給 group

  1. 位置⚙ Settings → System → Security → Global permissions。
  2. 授予選 permission → 選 group → Add。只能選 group（不能選 project role）。考綱寫「granted to groups」；現行文件另有 user 與 Anyone 選項，考試以 group 為準。
  3. 收回在列表中 Remove。
  4. 要給一個人先由 org admin 把他放進某個 group，再把權限給那個 group。
考題長相

「只想讓 Mia 能分享 dashboard」→ 建立（或使用）一個包含 Mia 的 group，再把 Share dashboards and filters 給這個 group。Global permission 不能直接給個人。

實作 Lab：Global permissions：@mention 與 bulk change

約 15 分鐘Jira admin

第一次做 Lab？先看 Lab 環境準備：用測試站台、準備測試帳號。畫面名稱可能隨 Atlassian 更新而不同，以下以現行畫面為準。

目標：拿掉兩個 global permission，看使用者的畫面少了什麼。

這個 Lab 對應的考點

Global permission 只能給 group（考綱）；Make bulk changes 要 global＋project 兩層；Browse users and groups 決定 @mention 看得到誰。

準備

  • 暫時把 Kim 從 WEB 的 Users role 移除，讓 Kim 在 WEB 沒有 Browse Projects（收尾時加回）。Leo 在 WEB 的 Developers。

步驟

  1. 你應該看到：Administer Jira 給了 jira-admins-xxx 一類的 admin group；Browse users and groups、Share dashboards and filters、Make bulk changes 等多半給了 jira-users-xxx 或所有使用者。
  2. 你應該看到：可以選 group（現行介面另有 user 與 Anyone）。考試以 group 為準。
  3. 你應該看到：Leo 可以進入 bulk change 精靈。
  4. 你應該看到：Make bulk changes 那一列只剩 admin group。
  5. 你應該看到：Bulk change 選項消失或無法使用；Leo 仍能一張一張編輯（Edit Issues 是 project 權限）。
  6. 你應該看到：Leo 又能 bulk change。

試試看：改一個設定，觀察差異

T1把 Browse users and groups 從一般使用者的 group 移除，用 Leo 在 WEB 的 issue 留言輸入 @Kim。看結果
找不到 Kim（Kim 在 WEB 沒有 Browse）；@ 只列出在 WEB 有 Browse Projects 的人。做完記得加回。
T2把 Create team-managed projects 從一般使用者移除，用 Kim 點 Create space。看結果
Kim 不能建 TMP；建 CMP 本來就要 Administer Jira。做完記得加回。

收尾

  • 確認 Make bulk changes、Browse users and groups、Create team-managed projects 都已加回原本的 group。
  • 把 Kim 加回 WEB 的 Users role。
