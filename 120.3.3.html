Screens 與 issue layout

3 分鐘速覽

Screen 三層＋issue layout

  1. Screen一組欄位（可有 tabs）；Jira admin 建立。
  2. Screen scheme依操作對應 screen：Create、Edit、View。
  3. Issue type screen scheme依 issue type 對應 screen scheme；套到 project。
  4. Transition screenWorkflow transition 上也可以掛 screen（例如 Resolve 時填 resolution）。
  5. Issue layoutProject admin 決定欄位在 issue view 的 description、context（含 hide when empty）、hidden 區。
  6. Copy issue layoutJira admin 可把 layout 複製到使用同一個 screen 的其他 project（覆蓋、不連動）。
資料來源（5）有疑慮時點開看官方原文
  • Create and set up work item screensScreens allow you to choose which fields are displayed on work items at different stages of your workflow.
  • Manage screen schemesWithin a screen scheme, you can associate each work item operation (create, view, edit) with a single screen.
  • Manage work type screensA work type screen scheme associates a screen scheme (which defines mappings between screens and work item operations) with work types.
  • Configure field layout in the work itemWhen configuring the layout, there are three sections: description fields, context fields, and hidden fields.
  • Copy a work item layout to other spacesCopying a work item layout doesn’t create a link between layouts.

Issue layout

Issue view 的欄位排列

  • Project settings → Issue layout（或 issue 上 Configure → Issue view）。
  • Description fields：左側（主要內容）；有 tabs 時也在這區。
  • Context fields：右側 Details；有 Hide when empty 分隔線：線以下的欄位沒值時收在 More fields。
  • Hidden fields：完全不顯示在 issue view。
  • 共用同一個 view screen 的 issue type 會一起設定。
  • 能加到 layout 的欄位＝view screen 上有的欄位；要加新欄位或 tab 要 Jira admin 改 screen。
  • Copy issue layout（Jira admin）：複製到使用相同 screen 的其他 project；會覆蓋對方、之後不連動。
本段必考
  • Layout 只排列、不新增欄位。
  • Copy layout 會覆蓋、不連動。
資料來源（5）有疑慮時點開看官方原文
  • Configure field layout in the work itemFields above the hide when empty are shown in the Details group and those below the line are hidden under the More fields group when they don't have a value.
  • Configure field layout in the work itemThis section is for fields that you don't want to appear on the work item at all.
  • Configure field layout in the work itemThe available fields for a work item type are the ones added in the global screen configuration for viewing that work type.
  • Copy a work item layout to other spacesSave time on space configuration by copying a screen’s work item layout to other spaces that use the same screen.
  • Copy a work item layout to other spacesCopying a work item layout will override layouts in the applied spaces.
TMP

Team-managed 的畫面

  • TMP 沒有 screen 與 scheme：每個 issue type 的欄位直接在 Project settings → Issue types 拖拉。
  • 欄位分成 Description fields、Context fields（含 hide when empty）與「建立時顯示」的設定。
  • 考試版：TMP 不能替 transition 加 screen。
本段必考
  • TMP 用 issue type 設定欄位，沒有 screen scheme。

動手做

實作 Lab：替 Bug 做專屬 Create screen，再排 layout

約 30 分鐘Jira admin（screen、scheme、Copy layout）；project admin（issue layout）

第一次做 Lab？先看 Lab 環境準備：用測試站台、準備測試帳號。畫面名稱可能隨 Atlassian 更新而不同，以下以現行畫面為準。

目標：走一次 issue type screen scheme → screen scheme → screen 三層，讓只有 Bug 的 Create 畫面多一個欄位；再用 issue layout 排列 view 的欄位。

這個 Lab 對應的考點

Issue type screen scheme → screen scheme（Create／Edit／View）→ screen；layout 只排列 view screen 上已有的欄位（description、context、hide when empty、hidden）。Copy issue layout 要 Jira admin，會覆蓋對方、之後不連動。TMP 沒有 screen，欄位在 issue type 上拖拉。

準備

  • WEB 有幾張 Bug。

步驟

  1. 你應該看到：Work type screen scheme 一列一個 work type（或 Default）對到一個 screen scheme；screen scheme 再把 Create、Edit、View 對到 screen。
  2. 你應該看到：WEB Bug Create 比原本的 screen 多了 Environment。
  3. 你應該看到：WEB Bug SS：Create 用 WEB Bug Create，Edit 與 View 用原本的 screen。
  4. 你應該看到：Bug 那一列顯示 WEB Bug SS；其他 work type 不變。
  5. 你應該看到：只有 Bug 的 Create 視窗有 Environment；打開 Bug 時通常看不到 Environment，因為 View 用的是另一個 screen。Create、Edit、View 可以各用不同 screen。
  6. 你應該看到：Labels 沒值時收在 More fields；加一個 label 後，它移到 Details。Hidden fields 裡的欄位完全不顯示。
  7. 你應該看到：找不到：layout 只能排 view screen 上已有的欄位。頁面上方有連到 screen 設定的連結，要加欄位或 tab 得由 admin 改 screen。
  8. 你應該看到：沒有 screen、screen scheme：欄位直接拖進 Description fields 或 Context fields，並有一條隱藏空欄位的虛線。

試試看：改一個設定，觀察差異

T1用 Leo（暫時加進 WEB 的 Administrators role）打開 WEB 的 Layout 頁。看結果
Leo 能排 layout，但看不到 Copy work item layout 按鈕，也不能改 screen：那是 Jira admin 的事。
T2建一個暫時的 CMP（Create space → Company-managed → 勾 Share settings with an existing space 選 WEB）。在 WEB 的 Layout 選 layout → Copy work item layout → 選這個新 space → Next → Copy layout。之後再改一次 WEB 的 layout。看結果
新 space 的 layout 被覆蓋成跟 WEB 一樣；之後改 WEB，新 space 不跟著變（複製不建立連結）。這個功能逐步推出中，看不到按鈕就當想像題。做完把暫時 space 移到 trash。
T3（想像，不實際做）想在 TEAM 的某個 transition 加 screen，讓人轉 Done 時填欄位。看結果
考試版本：TMP 不能替 transition 加 screen。Transition screen 是 CMP 的功能。
心像錨點：閉上眼睛想一次這個畫面

Work type screen scheme 頁：Bug 那一列指向 WEB Bug SS，WEB Bug SS 裡 Create 指向 WEB Bug Create。型→方案→畫面→排版；layout 只排、不加。

收尾

  • WEB 的 work type screen scheme 移除 Bug 的對應（Bug 回到 Default）；刪除 WEB Bug SS 與 WEB Bug Create。
  • Layout：把 Labels 與隱藏的欄位拖回原位 → Save changes。
  • Leo 移出 WEB 的 Administrators role；確認暫時 space 已移到 trash。
