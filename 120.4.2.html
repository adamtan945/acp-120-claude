3 分鐘速覽

TMP workflow：每個 issue type 一個，project admin 自己改

  1. 每個 issue type 各自的 workflowProject settings → Issue types → 選 type → Edit workflow。
  2. Status 與 board 欄位連動在 board 加一欄＝加一個 status；status 的 category 決定 To do、In progress、Done。
  3. Transitions可以從任何 status（Any status）或指定 status 轉入。
  4. Rules：restrict限制誰能移動（assignee、reporter、user、role、group、permission）、要經過某 status、欄位值條件、驗證權限。
  5. Rules：update自動指派（reporter、current user、no one、某人）、更新欄位、複製欄位值。
  6. Rules：validate移動前檢查欄位必填等。
Workflow rules

TMP 的三類 rule

類別Rule例子
Restrict（類似 condition）Restrict who can move a work item只有 QA role 能從 In review 移出
Restrict to when a work item has been through a status轉 Done 前最近的 status 必須是 In review
Restrict to when a work item is a specific valuePriority = Highest 才能走 Expedite
Validate that people have a specific permission有 Assign 權限才能開始
Validate（類似 validator）Validate a field（必填等）轉 Done 前 Fix version 不能空
Update（類似 post function）Assign a work item to someone到 In review 時指派給 QA
Update a work item field／Copy the value of one field to another到 Done 時設欄位、複製值
本段必考
  • TMP 的 rule 對應 CMP 的 condition／validator／post function。
Status 與欄位

建立、編輯、刪除

  1. 建 statusWorkflow editor 加 status，或在 board 加欄位（同時建 status）。
  2. Category每個 status 選 To do、In progress、Done；決定 board 與報表的分類。
  3. 改名TMP 改 status 名稱只影響這個 project（status 屬於該 project）。
  4. 刪除有 issue 在該 status 時，要先選把它們移到哪個 status。
  5. Transition建立轉換，可勾 Allow all statuses to transition to this one。
本段必考
  • TMP 改 status 名只影響自己。
易錯觀念

考題愛用的錯誤說法

TMP 所有 issue type 共用一個 workflow。
每個 issue type 可以有自己的 workflow。
官方來源
TMP 的 workflow 要 Jira admin 改。
Project admin 就能改。
官方來源
TMP 改 status 名稱會影響其他 project。
只影響這個 project。
官方來源
TMP 不能限制誰能移動 issue。
可以用 Restrict who can move a work item rule。
