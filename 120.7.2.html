附件、issue linking、app links、time tracking

  1. Attachments全站開關與大小上限（Settings → System → Attachments）；還要 Create Attachments 權限。
  2. Issue linking全站開關＋link types（outward、inward 描述，例如 blocks／is blocked by）；還要 Link Issues 權限。
  3. Application links連到 Confluence、其他 Atlassian 或第三方產品，讓兩邊互相顯示資料。
  4. App navigator 連結在 app switcher 加自訂連結。
  5. Time trackingSettings → Work items → Time tracking：每天幾小時、每週幾天、顯示格式、預設單位；停用或重新啟用都不會遺失資料。
  6. EstimationBoard 的 estimation statistic（story points 或 time）與 time tracking 是不同設定。
Linking

Issue linking 與 app links

設定說明
Issue linking on／off關掉後所有人都看不到 Link 選項，即使有 Link Issues 權限
Link types名稱＋outward description＋inward description，例如 Blocks：blocks／is blocked by
刪除 link type要選把既有連結轉成哪種 type，或一起刪除
Application linksJira ↔ Confluence 等：顯示相關頁面、建立連結
App navigator links在切換 app 的選單加入公司內部連結
本段必考
  • Link Issues 權限＋全站 linking 都要開。
Time tracking

啟用與設定

考試版／現行版

考綱寫「Enabling and configuring time tracking」。現行官方說明：Jira Cloud 的 time tracking 一律啟用，要不要用是靠 CMP 的 field configuration 顯示／隱藏 Time tracking 欄位、TMP 在 issue type 加或移除欄位；官方也明說停用或重新啟用都不會遺失既有資料。另外要給 Work On Issues 權限才能記工時。

症狀原因
看不到 Log workTime tracking 欄位被 field configuration 隱藏或不在 screen、或缺 Work On Issues 權限
「1d」的時數跟以前不同改了 working hours per day；既有估計以分鐘儲存，顯示換算改變
關掉 time tracking 後資料不見沒有刪除，重新開啟就回來
Board 燃盡圖用 story points、但想用時間那是 board 的 estimation 設定，不是全站 time tracking
本段必考
  • Time tracking 關掉不刪資料。
  • Hours per day 影響換算。
