3 分鐘速覽

附件、issue linking、app links、time tracking

  1. Attachments全站開關與大小上限（Settings → System → Attachments）；還要 Create Attachments 權限。
  2. Issue linking全站開關＋link types（outward、inward 描述，例如 blocks／is blocked by）；還要 Link Issues 權限。
  3. Application links連到 Confluence、其他 Atlassian 或第三方產品，讓兩邊互相顯示資料。
  4. App navigator 連結在 app switcher 加自訂連結。
  5. Time trackingSettings → Work items → Time tracking：每天幾小時、每週幾天、顯示格式、預設單位；停用或重新啟用都不會遺失資料。
  6. EstimationBoard 的 estimation statistic（story points 或 time）與 time tracking 是不同設定。
資料來源（5）有疑慮時點開看官方原文
  • Configure file attachmentsAttachments are enabled by default. You can configure the way Jira handles attachments, or disable attachments altogether.
  • Configure work item linkingNote that all users must have the Link Work Items permission before they can link work items.
  • Use AppLinks to link to Atlassian appsLinking Jira to other Atlassian apps allows you to include information from those apps directly in Jira spaces and work items.
  • Configure time trackingIt's enabled by default in Jira; you won't lose any existing data if you disable or re-enable it.
  • Configure how your board estimates and tracks workWhen configuring a board, you can set whether work items are estimated in story points, time estimate work items, and how progress is tracked throughout your sprint.

Time tracking

啟用與設定

考試版／現行版

考綱寫「Enabling and configuring time tracking」。現行官方說明：Jira Cloud 的 time tracking 一律啟用，要不要用是靠 CMP 的 field configuration 顯示／隱藏 Time tracking 欄位、TMP 在 issue type 加或移除欄位；官方也明說停用或重新啟用都不會遺失既有資料。另外要給 Work On Issues 權限才能記工時。

症狀原因
看不到 Log workTime tracking 欄位被 field configuration 隱藏或不在 screen、或缺 Work On Issues 權限
「1d」的時數跟以前不同改了 working hours per day；既有估計以分鐘儲存，顯示換算改變
關掉 time tracking 後資料不見沒有刪除，重新開啟就回來
Board 燃盡圖用 story points、但想用時間那是 board 的 estimation 設定，不是全站 time tracking
本段必考
  • Time tracking 關掉不刪資料。
  • Hours per day 影響換算。
資料來源（5）・1 點無官方原文有疑慮時點開看官方原文
  • 找不到官方原文：既有估計以分鐘儲存Configure time tracking 沒有寫明儲存單位；屬推論。
  • Configure time trackingShowing or hiding the Time tracking field in your company-managed space' field configurations.
  • Configure time trackingTo track their time, you must grant users the Work On Work Items permission in their space.
  • Configure time trackingThe number of hours in your working day (decimal values are accepted).
  • Configure time trackingIt's enabled by default in Jira; you won't lose any existing data if you disable or re-enable it.
  • Configure how your board estimates and tracks workEnable Time tracking if you’d like to use a different method to track progress on your board.

動手做

實作 Lab：新增 link type、關掉 linking、改一天幾小時

約 25 分鐘Jira admin

第一次做 Lab？先看 Lab 環境準備：用測試站台、準備測試帳號。畫面名稱可能隨 Atlassian 更新而不同，以下以現行畫面為準。

目標：建一個自己的 link type、看 outward／inward 兩個描述；關掉全站 linking 看權限擋不住；再改 Working hours per day，看既有工時的顯示怎麼變。

這個 Lab 對應的考點

全站 issue linking 關閉時，有 Link Issues 權限也不能連結；link type 有 outward 與 inward 兩個描述；time tracking 停用或重開不遺失資料；改 hours per day 會改變既有工時的換算顯示。

準備

  • Leo 在 WEB 的 Developers（有 Link Issues、Work On Issues）。
  • 挑 WEB 的三張 issue：A、B、C。

步驟

  1. 你應該看到：狀態是 ON；清單列出各 link type 的 Name、Outward description、Inward description（例如 Blocks：blocks／is blocked by）。
  2. 你應該看到：清單多了 Lab Depends。
  3. 你應該看到：A 顯示 depends on B；B 顯示 is depended on by A。同一條連結，兩邊各用一個描述。
  4. 你應該看到：Leo 看不到建立連結的選項：Link Issues 權限還在，但全站 linking 關了。看完按 Activate。
  5. 你應該看到：預設通常是一天 8 小時、一週 5 天。
  6. 你應該看到：C 的 time spent 顯示 1d 加上一小段；只填 2 的那筆，套用 admin 設的 default unit。
  7. 你應該看到：C 的 time spent 通常從 1d 左右變成 2d 左右：工時以實際時間儲存，1d 代表幾小時改了，顯示的換算就跟著變。看完改回 8。
  8. 你應該看到：Application links 用來連 Confluence 等產品；Attachments 是全站的附件開關與大小上限。

試試看：改一個設定，觀察差異

T1⚙ Settings›Work items›Permission schemes›WEB Permission Scheme → Work On Issues（Work On Work Items）把 Developers 拿掉。用 Leo 打開 C。看結果
Leo 不能 Log work：要記工時必須有這個 project 權限。做完加回。
T2刪除 Lab Depends（A 和 B 之間還有這條連結）。看結果
刪除時會問你：把既有連結改成另一個 link type（例如 Relates），或一起刪掉。選改成 Relates。
T3WEB 的 board → ••• → Board settings → Estimation（只看）。看結果
這裡選 Story points 或 Original Time Estimate、以及 board 要不要用 time tracking 看進度。這是 board 的設定，和剛才全站的 Time Tracking 不是同一件事。
心像錨點：閉上眼睛想一次這個畫面

Work item linking 頁：每列三格 Name、Outward、Inward，最上面一顆 Deactivate。開關在全站，權限在 project，兩個都要開。

收尾

  • 確認 Work item linking 是 ON；Lab Depends 已刪除。
  • Working hours per day 改回原值；Work On Issues 已加回 Developers。
  • C 的工時紀錄可以留著，或用 Work log 刪掉。

  • Configure work item linkingWhen you delete a link type, you'll have the option of changing the link (for example, from "Relates" to "Duplicates") or removing all related links.
  • Configure time trackingIt's enabled by default in Jira; you won't lose any existing data if you disable or re-enable it.
