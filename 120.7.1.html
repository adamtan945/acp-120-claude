3 分鐘速覽

全站外觀、使用者預設、default dashboard

  1. Look and feelSettings → System → Look and feel：logo、site title、顏色（Jira admin）。
  2. Announcement bannerSystem → Announcement banner：全站頂端訊息；可設 public（含匿名）或 private（只給登入者）。
  3. User default settings帳號建立時套用的預設：Email format、Work items per page、Default access（filter／dashboard 預設 public 或 private）、Notify users of their own changes、Autowatch own work items。
  4. Default vs personalDefault 只在帳號建立時套用；使用者之後可自己改。唯一例外：Email format 旁的 Apply 會強制所有使用者使用該格式，且使用者不能再改。
  5. Default dashboardJira admin 編輯（System dashboard）；沒自建 dashboard 的人看到它；匿名使用者也看這個。
  6. General configurationSite 名稱、預設語言、時區、Allow unassigned issues 等。

  • Configure the user default settingsAdministrators can change the default user settings which are applied to user accounts on creation.
  • Configure the user default settingsAn administrator can force the user to use a specific Email format by clicking the Apply link.
  • Configure the default dashboardAs a Jira admin, you can change the gadgets and the layout of this default dashboard to show the most important information for your team.
  • Configure Jira app optionsAs a Jira admin, you can manage the general configuration of all Jira apps in one place.

User default settings vs personal settings

User default settingsPersonal settings

考題長相

「Admin 把預設 email 格式改成 text，但舊使用者還是收到 HTML」→ 預設只在建立帳號時套用。要讓既有使用者也改用 text，按 Email format 的 Apply：會強制所有使用者使用該格式，使用者也不能再自行修改。

本段必考
  • Default 只在建立帳號時套用。
  • Email format 的 Apply＝強制全體、使用者不能改。

Default dashboard

System dashboard

  1. 位置⚙ Settings → System → User interface 區塊的 Default dashboard；可 Add gadget、Edit layout、Tools → View as Wallboard。
  2. 分享只能分享給 My organization（不含匿名）或 Public（任何人），不能指定 group、space 或個人；default dashboard 不能刪除。
  3. 編輯Jira admin 加、移、設定 gadget；gadget 要用所有人看得到的 filter，否則有人看到空白。
  4. 誰看到還沒建立自己 dashboard 的使用者、匿名使用者（若有權限）。
  5. 個人使用者可以 copy 它再自訂，或建立新的。

動手做

實作 Lab：改全站外觀、公告與使用者預設值

約 25 分鐘Jira admin

第一次做 Lab？先看 Lab 環境準備：用測試站台、準備測試帳號。畫面名稱可能隨 Atlassian 更新而不同，以下以現行畫面為準。

目標：改一次 look and feel、發一則 banner、改 user default settings 與 default dashboard，用 Leo 和 Kim 確認誰受影響、誰不受影響。

這個 Lab 對應的考點

User default settings 只在建立帳號時套用，唯一例外是 Email format 的 Apply（強制全體、使用者不能再改）；banner 可 public 或 private；default dashboard 只有 Jira admin 能改。

準備

  • Leo 沒有建立自己的 dashboard（120.6.2 的 Lab WEB 已刪除）。
  • 你有一個只有自己看得到的 filter，例如 Lab private（不分享給任何人）。

步驟

  1. 你應該看到：你和 Leo 的導覽列顏色都變了：look and feel 是全站設定。看完按 Revert 還原。
  2. 你應該看到：你和 Leo 的 Jira 頂端都出現黃色 banner，Leo 沒有關閉按鈕。
  3. 你應該看到：第一次打開時 Email format 預設顯示 text；直接按 Update 就會套用 text。
  4. 你應該看到：Kim 的設定沒變（You make changes 那一項維持原樣）：預設值只在帳號建立時套用，不改既有使用者。
  5. 你應該看到：Kim 的 email 格式通常變成 HTML 且不能再自己改：Apply 會強制所有使用者用這個格式。
  6. 你應該看到：Leo 看到的是 default dashboard，但那個 gadget 對他通常是空的或顯示無法存取：gadget 用的 filter 要所有人都看得到。
  7. 你應該看到：只有 My organization 與 Public 兩種，不能指定 group、space 或個人。

試試看：改一個設定，觀察差異

T1把 banner 的 dismiss 開關改成 ON，再發布一次。看結果
Leo 的 banner 多了關閉按鈕，關掉後就不再看到。
T2把 banner 改成 Public，並照 120.1.4 暫時把 WEB 的 Browse Projects 給 Public，用無痕視窗打開 WEB 的 issue。看結果
未登入的路人也看到 banner。Private 只給登入的使用者看。做完把 Browse Projects 的 Public 拿掉、banner 改回 Private。
T3（想像，不實際做）步驟 4 之後新邀請一位使用者。看結果
新使用者的 Notify users of their own changes 會是 Do not notify me：預設值只影響之後建立的帳號。
心像錨點：閉上眼睛想一次這個畫面

User Default Settings 頁：Email format 那一列旁邊有一個小小的 Apply。其他預設只給新人，只有 Apply 會蓋過所有人。

收尾

  • 把 Announcement banner 取消發布或清空訊息（依畫面提供的選項）。
  • User default settings 改回原本的值；移除 default dashboard 上的 Lab private gadget。
  • Email format 已被 Apply 成 HTML：官方沒有說明怎麼取消強制，所以步驟 5 一律選 HTML。
