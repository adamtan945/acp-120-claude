3 分鐘速覽

Status、resolution、priority 都是全站物件

  1. 建立Settings → Issues → Statuses／Resolutions／Priorities（Jira admin）。
  2. 改名影響全站CMP 的 status、resolution、priority 改名，所有使用它的 project、filter、board 都看到新名稱。
  3. TMP status屬於該 project，改名只影響自己。
  4. Resolution可設 default；有值＝已解決；不要放 create screen。
  5. Priority scheme不同 project 可以用不同 priority 清單。
  6. 停用 sub-tasksSettings → Issues → Sub-tasks；有 sub-task 存在時要先轉成 standard type。
全站物件

建立與改名的影響

物件建立後改名影響刪除
Status加進 workflow 才會用到；有 category所有用到的 workflow、board、filter 都變不能刪使用中的 status
Resolution出現在 resolution 欄位選單；可設 default全站要選把舊值換成哪個
Priority透過 priority scheme 給 project全站要選把舊值換成哪個
Issue type加進 issue type scheme全站要選把 issue 換成哪個 type
改名前想清楚

JQL 以 ID 儲存，改名不會讓 filter 壞掉，但所有 project 的使用者都會看到新名稱。只想某個 project 不同 → 建新的 status 或 priority scheme。

本段必考
  • CMP 的 status／resolution／priority 是全站共用。
Sub-tasks 與 TMP

停用 sub-tasks、TMP status

  • 停用 sub-tasks：全站開關；已有 sub-task 時，要先把它們轉成 standard issue type。停用後無法建立 sub-task。
  • TMP 的 status：每個 TMP 有自己的 status，改名、刪除只影響這個 project；不會影響其他 TMP 或 CMP。
  • Priority scheme：Settings → Issues → Priority schemes：替不同 project 指定不同的 priority 清單與預設值。
本段必考
  • TMP status 改名只影響自己。
