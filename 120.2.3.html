3 分鐘速覽

Version：一起發布的一組工作

  1. Fix version這張 issue 會在哪個版本完成；Affects version：問題出現在哪個版本。
  2. 名稱在 project 內唯一同一個 project 不能有兩個同名 version。
  3. Release 時有未解決的 issue選擇移到另一個 version，或忽略並照樣發布。
  4. Merge把多個 version 的 issue 併到一個 version；被併的 version 會刪除。
  5. Delete要決定 Fix／Affects version 的 issue 改指到哪個 version，或直接移除。
  6. Scrum vs KanbanScrum 先規劃再發布；Kanban 隨時發布已完成的工作，發布時才命名。

誰能管 version

  • 設定 issue 的 Fix version 要 Edit Issues（或 Resolve Issues 視 screen 而定）。

動手做

實作 Lab：Release 一個還有未完成工作的 version

約 25 分鐘Project admin 或有 Manage versions 權限

第一次做 Lab？先看 Lab 環境準備：用測試站台、準備測試帳號。畫面名稱可能隨 Atlassian 更新而不同，以下以現行畫面為準。

目標：建三個 version，帶著未完成的 issue 發布 v1.0，再 merge、delete、archive，看 issue 的 Fix version 怎麼變。

這個 Lab 對應的考點

Release 時有未解決的 issue：移到另一個 version，或忽略照樣發布；merge 後來源 version 被刪除；delete 要決定 issue 的 Fix／Affects version 改指到哪裡或移除；version 名稱在 project 內唯一；Kanban 可以隨時 release、release 時才命名。

準備

  • WEB 至少有 5 張 issue，其中一張已經是 Done。

步驟

  1. 你應該看到：Version panel 列出三個 version。
  2. 你應該看到：建不起來：同一個 project 的 version 名稱必須唯一（通常會提示名稱已存在）。
  3. 你應該看到：v1.0 出現進度條，依 status category 顯示完成與未完成的數量。
  4. 你應該看到：對話框要你決定未解決的 issue 怎麼處理，並填 release date。
  5. 你應該看到：v1.0 變成 Released；那 2 張未完成 issue 的 Fix version 變成 v1.1。
  6. 你應該看到：v1.1 從清單消失；原本在 v1.1 的 issue，Fix version 變成 v2.0。
  7. 你應該看到：Jira 問你用到它的 issue（Fix version、Affects version）要改指到別的 version 還是直接移除。選移除 → 那張 issue 不再有 Fix version。
  8. 你應該看到：v1.0 從大部分清單隱藏（例如編輯 Fix version 時的下拉選單）；但那張 issue 仍顯示 Fix version v1.0。

試試看：改一個設定，觀察差異

T1Release v2.0 時改選忽略未解決的 issue（Ignore and proceed），再搜尋 fixVersion = v2.0 AND resolution = Unresolved。看結果
照樣發布成功；未解決的 issue 仍留在已發布的 v2.0。有未完成也能 release。做完把 v2.0 改回 Unreleased。
T2看 WEB Permission Scheme 的 Manage versions 給了誰；用 Leo 打開 Releases。看結果
如果 Leo 不在 Manage versions 的對象裡、也不是 project admin，就不能建立或編輯 version。管 version 要 project admin 或 Manage versions。
T3（想像，不實際做）如果 WEB 是 Kanban，要怎麼 release？看結果
Kanban 不必事先把 issue 指到 version：隨時把已完成的工作 release，release 當下才命名 version。
心像錨點：閉上眼睛想一次這個畫面

Release 對話框：上面寫著還有幾個未解決的 issue，下面兩個選項：移到另一個 version，或忽略照樣發布。未完成擋不住 release，只是要你決定它們去哪。口訣：發、併、刪、封。

收尾

  • v1.0：取消封存後刪除（選擇從 issue 移除）。
  • v2.0 若已 release 就改回 Unreleased；保留 v2.0，120.4.1 的 Lab 會用到。
