3 分鐘速覽

Automation：trigger → condition → action，加 branch

  1. ScopeProject rule（project admin 可建）vs global／multi-project rule（Jira admin）。
  2. Trigger只能一個：created、transitioned、field value changed、scheduled、manual…
  3. ConditionIssue fields、JQL、user、related issues、{{smart values}}、If/else。
  4. Branch對 related issues（sub-tasks、parent、linked、JQL 結果）各跑一次。
  5. Smart values{{issue.summary}}、{{issue.parent.key}}、{{now.plusDays(1)}}、{{triggerIssue}}。
  6. Actor 與權限Rule 以 actor（預設 Automation for Jira）執行；actor 要有 project 權限，rule 才改得動 issue。
組成

一條 rule 的零件

零件說明例子
Trigger什麼時候執行（只能一個）Work item transitioned to Done
Condition不符就停；If/else 可分流Issue fields: issue type = Story
Branch對相關 issue 各跑一次後續動作For sub-tasks／For linked issues（blocks）
Action做什麼Transition、Edit、Comment、Send email、Create issue
Rule details名稱、owner、actor、scope、Allow rule trigger
考題長相

「Story 轉到 Done 時，把所有 sub-task 也轉 Done」→ Trigger：transitioned → Branch：For sub-tasks → Action：Transition to Done。「被 blocks 的 issue 都要通知」→ Branch：Linked issues（is blocked by）。

本段必考
  • 相關 issue → branch。
  • 一條 rule 一個 trigger。
Scope 與權限

Project rule vs global rule

Project ruleGlobal／multi-project rule
誰能建Project admin（Administer＋Browse Projects；可被 Jira admin 關閉）Jira admin（Administer Jira；任何 scope）
範圍單一 project多個 project、project type、全站
欄位、status這個 project 的所有 scope 內 project 都要一致
Usage依方案計算執行次數依方案計算執行次數
  • Rule 的變更以 actor 名義執行（預設 Automation for Jira；可改成某個使用者）；actor 缺權限（例如 Transition、Edit、Browse）時，audit log 會顯示錯誤。
  • 誰能建 rule：CMP 要 Administer Projects＋Browse Projects；TMP 要 Administrator；Jira admin 可在 Global automation → Global configuration 關掉 project admin 管理 rule 的能力。
  • Permission scheme 收緊後 rule 失敗：檢查 actor 是否仍有該 project 的對應權限（推論：官方未列出 actor 的權限來源細節）。
  • Allow rule trigger：允許此 rule 被其他 rule 的動作觸發（避免無限迴圈預設關閉）。
本段必考
  • Actor 沒權限 → rule 失敗。
  • Global rule 要 Jira admin。
